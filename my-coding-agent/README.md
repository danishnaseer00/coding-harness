# Coding Harness

An AI coding agent that runs in your terminal with streaming, multi-provider LLM support.

## Install

```bash
pip install git+https://github.com/your-username/coding-harness.git#subdirectory=my-coding-agent
```

## Use

```bash
cd your-project
harness
```

The agent reads `AGENTS.md` from your project for custom instructions.
